# Smart_Roads
SmartRoad lets citizens report road hazards — potholes, broken streetlights, faulty traffic signals, road damage, flooding, and debris — in seconds, see them plotted on a live map alongside real-time traffic conditions, and track which issues are open, in progress, or fixed.

Features
Report an issue — a quick form with problem type, severity, location (with geolocation support), description, and an optional photo.
Automatic priority scoring — every report is scored 0–100 and categorized (Low/Medium/High/Critical) based on severity and problem type, so the most dangerous issues surface first.
Live traffic overlay — TomTom Traffic Flow and Incidents layers on an interactive Leaflet map, plus a dashboard of real-time congestion at key Delhi corridors, auto-refreshing every 2 minutes.
Filterable issue dashboard — browse all reported issues by problem type, severity, and status, with live counts (total, open, critical, fixed).
Offline-first — the app works fully on browser storage even with no backend running, and syncs automatically when a server is available.
Zero-dependency backend — a REST API written entirely in Python's standard library; no database server or external packages required
